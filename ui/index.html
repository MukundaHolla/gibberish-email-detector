OPTIONAL · SECOND MACHINE-LEARNING MODEL

Train a domain model

Upload both domain files to train a second model alongside the email model. It learns spelling patterns from flagged and ordinary domains; the original domain lists are not saved as an exact-match list.

Subdomains are analyzed using their registrable domain: for example, mail.example.com uses example.com. The result is a prediction, so a domain from the training data is not guaranteed to be flagged.

No file selected · optional
Domain column name optional, for CSVLeave blank for a one-column list or a header named domain, domain_name, domain name, host, or hostname. Use full domains, not URLs or email addresses.

Provide both files, or leave both empty to train only the email model. Each domain list needs at least five different registrable domains, with enough examples for every split; this is a technical minimum, not an accuracy guarantee. The false-alert budget is used separately for each model; the combined false-alert rate can be higher. The saved model contains learned fragments and weights, which can reveal parts of the training data.

How much data can I upload?

The local app accepts up to 20 MiB for the entire training request, including both files and JSON encoding. The actual combined file size must be smaller. Training uses memory, so your computer can reach a practical limit sooner.

Both lists need at least 5 distinct eligible username groups each, and each split must contain both labels. This is only a technical minimum; more representative examples are needed to assess quality. The vocabulary is capped at 50,000 features.

Review & export

Review each prediction using the last column. For unsure or score-only results, choose a label directly or mark uncertain. Your review stays in this browser only; export before closing or running another batch.

TXT files contain only reviewed flagged or ordinary labels. Uncertain and unreviewed entries are omitted. Keep independent evaluation data separate from new training examples.
